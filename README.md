# Python System Resource Monitor

A Python-based system monitoring tool that displays real-time system resource usage, including CPU, RAM, disk, and network activity.

## Features

- Display system information.
- Monitor CPU usage.
- Monitor RAM usage.
- Monitor disk usage.
- Monitor network upload and download.
- Display real-time upload and download speeds.
- Automatically refresh monitoring data every 2 seconds.

## Requirements

- Python 3.9 or newer
- psutil

## Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/pradipta-web/python-system-resource-monitor.git
   ```

2. Navigate to the project directory:

   ```bash
   cd python-system-resource-monitor
   ```

3. Install dependencies:

   ```bash
   py -m pip install -r requirements.txt
   ```

## Usage

Run the application:

```bash
py main.py
```

Press `CTRL + C` to stop monitoring.
